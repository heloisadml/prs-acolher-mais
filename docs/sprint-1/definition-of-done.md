# Definition of Done — Sprint 1

Uma História de Usuário será considerada **Done** somente quando todos os critérios abaixo forem atendidos:

- [ ] Critérios de aceitação atendidos;
- [ ] Implementação concluída;
- [ ] Funcionalidade testada;
- [ ] Funcionalidade validada;
- [ ] Código revisado, quando aplicável;
- [ ] Código integrado à versão do projeto, quando aplicável;
- [ ] Ausência de erro crítico conhecido relacionado à história;
- [ ] Documentação atualizada.

## Base utilizada

Os templates já existentes no repositório definem como critérios mínimos:

### Template de User Story

- Implementado;
- Testado;
- Documentado.

### Template de Task

- Implementação concluída;
- Código revisado;
- Testes realizados;
- Documentação atualizada.

A Definition of Done desta Sprint consolida esses critérios em uma regra única para todas as histórias.

## Regra para contabilização

Uma história só poderá ser contabilizada na **velocity** quando atender integralmente à Definition of Done.

Histórias parcialmente implementadas ou com algum item obrigatório pendente não devem ter seus Story Points contabilizados como concluídos.
